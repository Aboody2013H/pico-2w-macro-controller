# v4.1.0 — DEBUG and RELEASE-HIDDEN drive variants

Both UF2 files use the unchanged v4.0.1 instant 500-CPS macro engine. The only
difference is USB mass-storage visibility.

## DEBUG

`Pico-2W-Macro-v4.1.0-DEBUG-MACRO-DRIVE.uf2`

- Shows the writable CircuitPython filesystem over USB.
- The volume label is `MACRO` instead of `CIRCUITPY`.
- Use this build to edit `code.py`, HTML, macros, and `settings.toml`.

## RELEASE-HIDDEN

`Pico-2W-Macro-v4.1.0-RELEASE-HIDDEN-DRIVE.uf2`

- Includes `boot.py` calling `storage.disable_usb_drive()`.
- The macro system, website, Wi-Fi, HID, BOOTSEL, LED, and serial console remain.
- The USB storage volume is hidden during normal boots.

## Recovering visible drive access

Enter the RP2350 BOOTSEL bootloader and flash the DEBUG UF2. The DEBUG image
replaces the hidden filesystem with one that has no drive-disabling `boot.py`,
so the `MACRO` volume becomes visible again after reboot.

Both assets contain placeholder Wi-Fi settings, not personal credentials.
