# v1.0.0 — CircuitPython BOOTSEL Base

Custom CircuitPython 10.2.1 firmware for Raspberry Pi Pico 2 W/RP2350A with the
native `bootsel.pressed()` API. This release contains no website, macro, or saved
Wi-Fi credentials. Existing CIRCUITPY contents may remain after flashing.

Asset: `Pico-2W-CircuitPython-10.2.1-BOOTSEL-Base.uf2`
