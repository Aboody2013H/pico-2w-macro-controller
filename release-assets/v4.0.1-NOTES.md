was applying its own 1 ms transition schedule on top of the USB HID endpoint's
readiness pacing. The duplicate pacing is removed.

- Eight-click bursts amortize web-loop overhead.
- BOOTSEL and website Mouse Turbo use the same full-speed engine.
- BOOTSEL press-edge activation and website activation remain immediate.
- Web/BOOTSEL polling resumes approximately every 16 ms while clicking.
- Credential-safe placeholder Wi-Fi configuration is preserved.
