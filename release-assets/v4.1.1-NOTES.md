# v4.1.1 — Exclusive macros and touch-scroll fix

This patch keeps the v4.1.0 DEBUG and RELEASE-HIDDEN variants while fixing the
website control bugs.

## Changes

- Only one macro can run at a time. Starting Mouse Turbo, Space Turbo, AFK
  Walk, BOOTSEL autoclicker, or a custom macro safely stops and releases the
  previous one.
- Ubuntu Terminal, Command Prompt, and Alt+F4 now stop all macros before
  sending their shortcut.
- Fixed the asynchronous hold race that could restart Space Turbo after a
  quick tap had already ended.
- Touch users can drag vertically over buttons to scroll without activating
  them. Hold controls activate only after a short stationary 140 ms press;
  moving 12 px cancels the press and leaves scrolling to the browser.
- Custom hold macros use the same scroll-safe gesture behavior.

## Variants

- `Pico-2W-Macro-v4.1.1-DEBUG-MACRO-DRIVE.uf2` shows the writable `MACRO`
  drive for editing and troubleshooting.
- `Pico-2W-Macro-v4.1.1-RELEASE-HIDDEN-DRIVE.uf2` hides USB storage during
  normal boots.

The public assets contain placeholder Wi-Fi settings, not personal
credentials.
