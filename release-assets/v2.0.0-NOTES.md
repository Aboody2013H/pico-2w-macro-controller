# v2.0.0 — BOOTSEL Autoclicker 500 CPS + LED

Standalone native Pico 2 W autoclicker. Press BOOTSEL to toggle approximately
500 clicks per second. The onboard LED is lit while clicking. There is no
CircuitPython drive, Wi-Fi, web dashboard, or editable `code.py` in this build.

Asset: `Pico-2W-BOOTSEL-Autoclicker-500CPS-LED.uf2`
