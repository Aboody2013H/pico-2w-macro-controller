# v4.0.0 — Instant Response Build

The complete Pico 2 W web + BOOTSEL firmware with activation waits removed:

- BOOTSEL toggles the autoclicker on the first detected press edge.
- Mouse Turbo activates on the first `/mouse/start` request.
- Space Turbo activates on the first `/space/start` request.
- The former 750 ms BOOTSEL hold, 300 ms release-arm, 50 ms debounce, and
  250 ms website arming waits are removed.
- Approximately-500-CPS mouse output, 1 ms HID polling, Wi-Fi fallback, LED,
  macro builder, no-cache headers, heartbeat leases, and emergency HID release
  remain available.

This credential-safe release contains placeholder Wi-Fi settings. Edit
`settings.toml` on CIRCUITPY after flashing.

Asset: `Pico-2W-Macro-Web-BOOTSEL-Instant.uf2`
