# v3.0.0 — Complete Pico 2 W Macro Web + BOOTSEL Build

One-flash recovery image containing custom CircuitPython 10.2.1, native BOOTSEL
support, 1 ms HID polling, the restored web dashboard, macro builder, writable
CIRCUITPY filesystem, LED indication, approximately-500-CPS mouse engine, and
three-network boot fallback.

This public release-safe image contains placeholder Wi-Fi settings. After flashing,
edit `settings.toml` on CIRCUITPY with your own networks and reboot.

Asset: `Pico-2W-Macro-Web-BOOTSEL-Combined.uf2`
